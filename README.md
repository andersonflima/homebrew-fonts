# homebrew-fonts

Homebrew tap com fontes pessoais.

```bash
brew tap andersonflima/fonts
brew install --cask font-crowquill-mono
```

## Casks

- `font-crowquill-mono` — [Crowquill Mono](https://github.com/andersonflima/crowquill-mono): fonte de programacao que deixa keywords em negrito automaticamente (base JetBrains Mono, OpenType `calt`).
